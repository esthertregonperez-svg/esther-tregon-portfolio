
📱 BusinessManager AppSheet

Aplicación de gestión empresarial desarrollada con Google AppSheet

BusinessManager AppSheet es una aplicación empresarial desarrollada con Google AppSheet cuyo objetivo es digitalizar y centralizar la gestión diaria de pequeños y medianos negocios mediante una solución móvil rápida, intuitiva y sin necesidad de programación tradicional.

Como caso práctico, la aplicación ha sido implementada para la gestión de una tienda especializada en animales exóticos, permitiendo administrar ventas, gastos, categorías, agenda y obtener un resumen gráfico de la actividad del negocio desde cualquier dispositivo.

El proyecto demuestra la capacidad de diseñar aplicaciones empresariales utilizando herramientas Low-Code, facilitando la automatización de procesos y la organización de la información de forma eficiente.

---

🎯 Objetivos

- Digitalizar la gestión de pequeños negocios.
- Centralizar la información en una única aplicación.
- Facilitar el registro de ventas y gastos.
- Organizar productos mediante categorías.
- Gestionar tareas y eventos mediante agenda.
- Visualizar la evolución del negocio mediante gráficos.
- Demostrar el desarrollo de soluciones empresariales con AppSheet.
